# 学习规划 Agent 实战

## 最终目标

实现一个命令行学习规划 Agent。用户输入学习主题、可用天数和每天可用分钟数后，Agent 会自主决定是否调用工具，并给出可执行的学习计划。

## 功能边界

- 支持的主题：Python、FastAPI、LangChain
- 能精确计算总学习时长，计算必须交给工具完成
- 能查询本地内置的主题学习大纲
- 信息不足时先追问，不擅自编造天数或学习时长
- 第一版不联网、不读写数据库、不使用多 Agent

## 为什么选这个项目

这个任务同时包含两类工作：

1. 语言模型擅长的工作：理解需求、判断缺少什么信息、组织学习计划。
2. 普通函数更可靠的工作：精确计算、查询确定的数据。

Agent 的价值不是“调用了大模型”，而是让模型根据当前问题自主选择工具，并根据工具结果继续完成任务。

## 学习关卡

1. 模型基线：验证模型和环境，但暂时不使用工具。
2. 工具设计：实现并单独测试两个普通函数。
3. Agent 组装：把模型、系统提示词和工具交给 `create_agent`。
4. 轨迹观察：辨认模型消息、工具调用消息和工具结果消息。
5. 多轮对话：加入 `thread_id` 和短期记忆。
6. 边界验证：测试正常输入、信息不足和越界主题。

## 最终验收示例

输入：

```text
我想用 7 天复习 LangChain，每天 45 分钟，请帮我安排。
```

验收要求：

- Agent 调用“计算学习预算”工具，得到 315 分钟。
- Agent 调用“查询学习大纲”工具，获取 LangChain 大纲。
- 最终计划覆盖 7 天，总时长不超过 315 分钟。
- 最终回答不伪造工具没有提供的资料或链接。
